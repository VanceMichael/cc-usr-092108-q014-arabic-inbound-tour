# 阿拉伯家庭入境团履约

记录入境家庭、定制行程、供应商承诺和隐私授权，支撑定制团从现场报价到履约沉淀的全流程。

## 领域资料

`contracts/` 定义共享资料格式，`fixtures/` 提供可公开使用的虚构样例（八口之家、五类供应商、现场口头报价、两版重庆行程、重庆祈祷与用餐窗口）。样例不含真实个人信息、账号、密钥或连接凭据。

当前资料反映以下业务事实：

- 阿拉伯国家游客对中国定制旅行需求上升
- 中国企业与当地机构持续对接旅游产品
- 便利化政策和本地化服务影响行程体验

## 履约能力

| 模块 | 职责 |
| --- | --- |
| `src/privacy.py` | 成员关系、证件核验、偏好、无障碍、授权分库存储；按服务目的最小披露；证件有效期与签证预警 |
| `src/itinerary.py` | 行程版本管理：每次改版输出价格差额与逐项价格/可用性变化；客人视图始终指向唯一确认版本 |
| `src/callbacks.py` | 供应商回调按（供应商, 幂等键）登记，重复回调返回原单不生成双单；报价有效期一律按 UTC 判定 |
| `src/settlement.py` | 依合同结算定金、取消分档退款、部分参加退款、替换供应商差额承担；跨币种按汇率快照折算 |
| `src/review.py` | 阿拉伯语内容须由作者以外的人审校通过，方可面向客人发布 |
| `src/conflicts.py` | 方案确认前检测行程与祈祷、用餐窗口（含缓冲）的冲突 |
| `src/audit.py` | 承诺台账记录每项承诺的确认人与履行结果；证据日志以摘要链接，突发联络与投诉可追溯、篡改可发现 |
| `src/capability.py` | 已履行承诺沉淀为服务能力记录（人群规模分档、月份粒度），禁止包含个人资料字段 |
