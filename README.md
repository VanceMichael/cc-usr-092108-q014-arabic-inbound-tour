# 阿拉伯家庭入境团履约

记录入境家庭、定制行程、供应商承诺和隐私授权，支撑"一家八口单独成团赴重庆"这类
多代阿拉伯家庭私家团的完整履约：从展台口头报价到回程落地、投诉结算与能力沉淀。

## 领域资料

`contracts/context.schema.json` 定义共享资料格式，`fixtures/context.json` 提供可公开使用的虚构样例。领域资料按版本保存参与者、事实与约束，代码中的读取器负责检查必要字段。

当前资料反映以下业务事实：

- 阿拉伯国家游客对中国定制旅行需求上升
- 中国企业与当地机构持续对接旅游产品
- 便利化政策和本地化服务影响行程体验

## 业务场景（虚构样例）

2026 年迪拜 ATM 旅游展上，一户八口之家（祖辈2人、夫妻2人、4名子女，最小3岁）
咨询重庆5日私家团。口头报价2小时内有效、回程航班未确认即失效；证件、酒店、
阿语向导、清真餐饮、用车、分龄活动分属不同供应商。资料包按此场景给出全部样例。

## 分层资料（`fixtures/booking/`）

个人资料按用途分文件保存，彼此用 `guest_id`（G1–G8）关联：

| 文件 | 内容 |
|---|---|
| `family.json` | 成员关系、年龄层、监护关系、咨询来源（展台） |
| `documents.json` | 证件核验历史（G7护照不足6个月先阻断后换发、G8出生证明补料） |
| `preferences.json` | 语言、清真、房型、分龄偏好、坚果过敏 |
| `accessibility.json` | 祖父轮椅需要、助听器、婴儿座椅等无障碍安排 |
| `consents.json` | 按供应商×用途×字段×成员的授权范围（营销明确拒绝） |
| `suppliers.json` | 8 类供应商能力、SLA 与平替条件 |
| `route.json` | 重庆5日路线（含周五主麻安排项） |
| `quote_samples.json` | 三版报价：口头失效 / 邮件失效 / 定金锁定 |
| `plan_versions.json` | 方案 v1→v3 及逐版价格与可用性差异 |
| `contract_terms.json` | 定金、取消梯度、部分参加、供应商平替、价格锁定 |
| `settlement.json` | 结算流水（定金、部分参加、平替差价、投诉赔付） |
| `callbacks.json` | 跨时区三次同一回调，幂等抑制为一单 |
| `arabic_content.json` | 阿语内容审校轮次（主麻误译曾被拦截） |
| `prayer_schedule.json` | 重庆五时时刻表与餐饮时段、冲突与提前解决方案 |
| `commitments.json` | 承诺台账：承诺/确认人/确认时间/供应商单号/履行结果 |
| `event_log.json` | append-only 事件链：服务记录、突发、投诉、处理 |
| `guest_itinerary.json` | 客人持有的唯一一致行程（中阿双语、改版留痕） |
| `service_capabilities.json` | 去标识化的服务能力沉淀（不含任何个人资料） |

样例全部为虚构，不含真实个人信息、账号、密钥或连接凭据。

## 履约规则代码（`src/`，仅标准库）

- `records.py` 组装资料包；`documents.py` 证件阻断式核验（全部通过才放行出票）
- `privacy.py` 供应商最小披露：按授权投影字段，餐饮只见餐码不见姓名，营销拒绝即不披露
- `pricing.py` 报价到期判定、合计校验、改版价格/可用性差异、未确认资源缺口
- `schedule.py` 礼拜（含周五主麻）与餐饮时段冲突的提前检测
- `orders.py` 跨时区回调幂等：键为 `资源|供应商|callback_id`，重复回调不生双单
- `content.py` 阿语审校门禁：机翻仅作草稿，approved 才能对客
- `commitments.py` / `itinerary.py` 承诺台账与客人行程三方一致
- `evidence.py` 投诉必须挂接事件、赔付必须挂接投诉处理
- `capabilities.py` 能力沉淀去标识化扫描（姓名/证件/电话/单号/精确日期）

`contracts/fulfillment.schema.json` 给出组装后资料包的契约形状。

## 本地校验

```bash
python -m unittest discover -s tests     # 15 项测试
python tools/verify_booking.py           # 端到端规则校验
```

校验覆盖：八口监护关系、证件先阻断后闭环、口头报价失效、三版改版差异、
供应商最小披露、跨时区重复回调只成一单、阿语审校拦截、礼拜冲突全部有预案、
行程与承诺台账一致、投诉证据链可追溯、平替差价依合同承担、能力库无个人资料。
